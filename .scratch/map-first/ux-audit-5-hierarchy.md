## สรุปสั้นที่สุด

ปัญหาส่วนใหญ่ **ไม่ได้มาจากขนาดตัวอักษรที่ใช้** หน้า Rabbit ก็ใช้ชุดขนาดเดียวกันทุกตัว (32 / 20 / 16 / 14px)
ที่หน้า Rabbit ดูเป็นระเบียบเพราะมี **ชั้นกลาง** ที่หน้าอื่นไม่มี ได้แก่ หัวหน้าที่เป็นแถบสี, หัวข้อ section ("เตรียมให้พร้อม", "ทำตามนี้ 5"),
หมายเลขขั้น และกล่องที่แยกกลุ่มชัดเจน ส่วนหน้าอื่นมีแค่ h1 แล้วตามด้วยรายการยาวที่ทุกชิ้นหน้าตาเหมือนกัน

อีกเรื่องคือ ขนาดแต่ละขั้นถูกใช้ปนกันระหว่างหน้าที่ต่างกัน
- **20px (`--step-1`)** ใช้กับ lede, เนื้อโน้ต, หัวข้อ section ของ Guide, หัวข้อ "ถ้าหนักเกินไป" และหัวข้อ "รสชาติบ้าน"
- **24px (`--step-2`)** ใช้กับแถบหมวด, ชื่อรุ่นพี่, หัวฟอร์ม และเบอร์โทร

ผลคือ บทบาทเดียวกันได้หน้าตาต่างกันในแต่ละหน้า ส่วนบทบาทที่ต่างกันกลับได้หน้าตาเดียวกัน

## อะไรที่ทำดีอยู่แล้ว

- h1 ทุกหน้าเท่ากัน (32/700) และ wordmark อยู่ตำแหน่งเดียวกันทุกหน้า ผู้ใช้รู้ว่าตัวเองอยู่หน้าไหน
- หน้าโน้ต: chip กรองอยู่ใกล้รายการ (16px) มากกว่าใกล้ปุ่ม (32px) ซึ่งจัดกลุ่มตาม proximity ถูก และหัว Feed มีปุ่มหลักอันเดียวตามที่ ADR ระบุ
- หน้าโน้ต: meta เบากว่าเนื้อหาถูกต้อง (14px เทา เทียบกับ 20px สีหมึก) เนื้อหาไม่ได้แพ้ chrome ในตัวโน้ตเอง
- สัปดาห์แรก: วงกลมบนเส้นเป็นภาษาเดียวกับ station ของ Guide เห็นครบ 7 ข้อบนจอแรก
- วิธี (list): แถบหมวดสีทึบแบ่ง section ได้ชัด แถวมี icon + ชื่อ 16/700 + สรุป 14 + › สแกนได้ดี เป็นหน้าที่ดีที่สุดในกลุ่มนี้
- ช่วยเติม: ฟอร์มแยกกันด้วยเส้นและช่องว่าง 65px เทียบกับ 24px ภายในฟอร์ม สัดส่วนนี้ถูกต้อง
- ระยะ (`--space-*`) มี scale ชัดและส่วนใหญ่ใช้ตามคอมเมนต์

### D2: Feed ให้โน้ตเป็นพระเอก (หน้า /notes, /notes?line=)

2. ทำ chip ให้เบากว่าปุ่มหลัก เช่น สูง 36px (พื้นที่กดยังเป็น 44px) ขอบ 1px หรือสีอ่อน
3. เพิ่มป้ายหมวดเป็นตัวอักษรใน meta ของโน้ต เช่น "ของกิน · พี่บอส บ้านอยู่สุราษฎร์ฯ · @ที่" เพื่อไม่ให้สีเป็นตัวบอกหมวดอย่างเดียว และตัดช่องล่างของการ์ดที่เกินมาราว 30px
4. เมื่อกรองแล้วให้หัวหน้าบอกสถานะ เช่น h1 "โน้ต · ของกิน" หรือบรรทัด "2 โน้ตเรื่องของกิน"

### D3: สัปดาห์แรกให้ "ข้อถัดไป" เป็นจุดเริ่ม (หน้า /checklist)

### D4 (คำถามสำหรับเจ้าของ): ใช้ "หัวหน้าเป็นแถบสีอ่อน" แบบหน้า Guide กับทุกหน้า

หน้า Rabbit ดูเป็นระเบียบส่วนหนึ่งเพราะหัวหน้าเป็นแถบสีอ่อน ทำให้ "ส่วนหัว" กับ "เนื้อหา" แยกกันทันที ถ้าใช้แถบนี้กับ /notes, /checklist, /seniors, /contribute (สีหมึกอ่อนหรือสีหมวดเมื่อกรอง) ปัญหา N1, X2, X3 จะดีขึ้นพร้อมกัน

**ข้อที่ต้องถามเจ้าของ:** ADR 0006 / Q1a กำหนดว่าการ์ดมีเงาบนพื้นเทาเป็น "ลุคของหน้า Guide เท่านั้น" ส่วนหน้าอื่นให้แบนด้วยเส้นหรือแถบ ตัวแถบสีอ่อนเองเป็น "แถบ" ไม่ใช่การ์ด จึงน่าจะไม่ขัด แต่จะทำให้หน้า Guide ดูพิเศษน้อยลง ยอมรับได้ไหม
และถ้าเจ้าของอยากให้ Feed เป็นการ์ดขาวบนพื้นเทาแบบหน้า Guide ข้อนั้น **ขัด Q1a โดยตรง** ต้องตัดสินใจใหม่และแก้ ADR ก่อน ผู้ตรวจแนะนำให้คงความแบนไว้ แล้วใช้ D1 กับ D2 แทน

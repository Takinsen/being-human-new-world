- **[สูง]** = ข้อความตัวอย่างจากโดเมนทางการ และแหล่งอื่นให้ข้อมูลตรงกัน

- **[ต่ำ]** = บล็อก/UGC/ไดเรกทอรี หรือแหล่งขัดแย้งกัน

## 3. เดินทางจาก BTS/MRT ไปจุฬาฯ + ค่าโดยสาร

### BTS สยาม
- สถานีที่ใกล้จุฬาฯ ที่สุดคือ BTS สยาม และ BTS สนามกีฬาแห่งชาติ มีรถป๊อปรับเข้ามหาวิทยาลัย — https://www.chula.ac.th/en/contact/map-and-directions/ [กลาง]
- **ทางออกเฉพาะและเวลาเดินจาก BTS สยาม: ไม่พบแหล่งยืนยัน** (หน้า Map & Directions ของจุฬาฯ เปิดอ่านไม่ได้; ข้อความตัวอย่างพูดถึง "Exit 2 ... Chamchuri Square" ซึ่งเป็นทางออกของ **MRT สามย่าน** ไม่ใช่ของ BTS สยาม) แนะนำเขียนว่า "เดินผ่านสยามสแควร์ไปทางถนนอังรีดูนังต์ หรือขึ้นรถป๊อปสาย 1/4" โดยยังไม่ระบุเลขทางออก

### MRT สามย่าน (BL27)
- **ทางออก 2** ไปถึงจามจุรีสแควร์ (อาคารของจุฬาฯ) แล้วเดินต่อเข้าแคมปัส / นั่งรถ / แท็กซี่ ; จากตรงนั้นเดินไปคณะอักษรศาสตร์ประมาณ **10 นาที** — https://www.chula.ac.th/en/contact/map-and-directions/ ; https://www.arts.chula.ac.th/eng/index.php/map-and-directions/ [กลาง]
- ทางออก 2 มีอุโมงค์ใต้ดินเชื่อมเข้าชั้น B1 ของสามย่านมิตรทาวน์ — FB ทางการของ Samyan Mitrtown: https://www.facebook.com/SAMYANMITRTOWN/posts/398318985873513/ ; หน้าสถานี BEM: https://metro.bemplc.co.th/Line-Maps?Line=1&Station=27 [กลาง]

## 4. วิธีขึ้น MRT (ขั้นตอนทางการ)

1. **ใช้บัตรเครดิต/เดบิต EMV Contactless:** แตะบัตรที่ประตูอัตโนมัติ (ที่มีสัญลักษณ์ Contactless) **ตอนเข้าและตอนออก ด้วยใบเดิม** ; หนึ่งคนหนึ่งบัตร ; ไม่ต้องลงทะเบียนก่อน (ลงทะเบียนภายหลังเพื่อดูประวัติการเดินทางได้) ; ถือบัตรไว้ในมือ (ไม่แตะทั้งกระเป๋าสตางค์) — https://metro.bemplc.co.th/MRTEMV-Contactless ; https://metro.bemplc.co.th/EMV-Contactless-FAQs [สูง]

3. บัตร MRT รุ่นเดิม/MRT Plus **ใช้ไม่ได้แล้ว** ตั้งแต่ 1 มิ.ย. 2569 (ดูข้อ 3) [สูง]

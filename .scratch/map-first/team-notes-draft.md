# ร่างโน้ตให้ทีมโพสต์ (A1, A5)

ให้คนในทีมโพสต์ผ่านหน้า "เขียนโน้ต" บนเว็บ (`/notes/new?place=<id>`) **ในชื่อเล่นและจังหวัดบ้านเกิดจริงของตัวเอง** แก้ถ้อยคำให้เป็นคำพูดของตัวเองได้เลย และลบทิ้งข้อที่ตัวเองไม่เคยลองจริง โน้ตจะลง Google Sheet ทันที ไม่ต้องแก้โค้ด

ข้อเท็จจริงในร่างมาจาก `content/places.ts` และ `.scratch/map-first/content-research.md` ส่วนความเห็นหรือประสบการณ์ ต้องเป็นของคนที่ลงชื่อเท่านั้น

ถ้ามีคนในทีมที่บ้านอยู่กรุงเทพฯ ให้เขียนด้วยอย่างน้อย 1–2 โน้ต เพราะคนกรุงเทพฯ ที่เพิ่งอยู่หอครั้งแรกก็เป็นคนมาใหม่เหมือนกัน (A5)

| ที่ (`place`) | ร่าง |
|---|---|
| `mrt-samyan` | บัตร MRT แบบเก่าใช้ไม่ได้แล้ว แตะบัตรเดบิตที่มีรูปคลื่นได้เลย ออกทางออก 2 เดินเข้าจุฬาฯ ได้ |
| `bts-siam` | จากสยามไม่ต้องเดินตากแดด รอรถป๊อปสาย 1 หรือ 4 ฟรี ดูว่ารถถึงไหนในแอป CU NEX |
| `bts-national-stadium` | อยู่หอฝั่งบรรทัดทองลงสถานีนี้ใกล้กว่าสยาม มีรถป๊อปสาย 2 เข้ามหาลัย |
| `samyan-mitrtown-food` | แลกบัตรก่อนสั่ง เงินที่เหลืออย่าลืมคืนที่เคาน์เตอร์ ไม่งั้นค้างในบัตร |
| `samyan-market` | ชั้นบนมีข้าวราดแกงให้เลือกเยอะ บอกก่อนตักว่าเอากี่อย่าง |
| `banthat-thong` | ร้านเปิดดึก กินหลังเลิกติวได้ ดูราคาหน้าร้านก่อนสั่ง |
| `niyom-paktai` | (ให้คนจากภาคใต้เขียน ถ้าลองแล้วรสเหมือนบ้าน ติ๊ก "รสชาติบ้าน") |
| `somtam-chula-20` | (ให้คนจากภาคอีสานเขียน ถ้าลองแล้วรสเหมือนบ้าน ติ๊ก "รสชาติบ้าน") |
| `chula-hospital` | ไม่ฉุกเฉินไปศูนย์บริการสุขภาพที่จามจุรี 9 ชั้น 2 ก่อน นิสิตไม่เสียเงิน พกบัตรนิสิต |
| `otteri-im-park` | เครื่อง 9 กก. พอสำหรับผ้าหนึ่งสัปดาห์ ซักเสร็จรีบเอาออก คนรอคิวอยู่ |
| `samyan-mitrtown-supermarket` | น้ำแพ็คใหญ่ถูกกว่าซื้อขวดจากร้านสะดวกซื้อทุกวัน |

โน้ตที่ไม่ผูกกับที่ (เลือกหมวดเอง) เช่น
- อยู่คนเดียว: สัปดาห์แรกยังไม่ต้องซื้อเครื่องกรองน้ำ ลองตู้หยอดเหรียญก่อน แต่ดูสติกเกอร์ใบอนุญาตที่ตู้ด้วย
- การเดินทาง: ถามราคาวินก่อนขึ้นทุกครั้ง ถ้ามีป้ายราคาติดอยู่ก็ดูป้าย

# ตรวจ Visual Design และ Hierarchy รอบ 7: หลังเปลี่ยนเป็น "ใต้ร่มจามจุรี"

ตรวจเมื่อ 2 ต.ค. 2026 บน production build `localhost:3005` (ข้อมูล mock) ที่ 390×844 (full page และ fold), 1280×800 และ 360×740 รวมถึงสัปดาห์แรกที่ติ๊กแล้ว 3/7 และ 7/7
ภาพหน้าจอและสคริปต์อยู่ใน `audit7/visual/` ได้แก่ `m-*`, `w-*`, `s-*`, `z-*` (ซูม 2x), `m-checklist-3.png`, `m-checklist-7.png` และ `measure.json`
แผนที่เป็นสีเทาเพราะ sandbox บล็อก tile ข้อนี้จึงไม่นับเป็นปัญหา

## สรุปคำบ่นเดิมของเจ้าของ

## ข้อค้นพบ (เรียงตามผลกระทบ)

### V1 [สูง] Desktop 1280: ทุกหน้า (ยกเว้นแผนที่) ยังเป็น "กระดาษแผ่นเดียว" และ canopy ถูกยืดจนเสียรูป
- **ที่เห็น:** `/notes`, `/guides`, `/guides/*`, `/seniors`, `/checklist` เป็นคอลัมน์เดียว `.feed` x=296 กว้าง 688px บนพื้น `--ground` เรียบ ข้างละ 296px ว่างเปล่าตลอดความสูง 1900–2300px canopy สูง 104px เท่ามือถือ แต่ `Canopy.tsx` ใช้ `preserveAspectRatio="none"` บน `viewBox 0 0 400 120` เมื่อกว้าง 1280 จึงยืดแนวนอน 3.2 เท่า แต่แนวตั้ง 0.87 เท่า ลอนพุ่มไม้แบนเป็นคลื่นยาว และ "แสงลอด" (`circle r=2–3.5`) กลายเป็นวงรีแบน ~3.7:1 (ดู `w-notes.png`, `w-guides.png` แถบบนสุด) ส่วน wordmark บน desktop มีขนาดแค่ 20px
- **ทำไมเสีย:** pitch ถูกตัดสินบน projector ก่อน และจอนี้คือภาพที่ "แปะ element บนกระดาษ" ชัดที่สุด ต้นไม้ที่ถูกยืดอ่านเป็นลายคลื่น ไม่ใช่ร่มไม้ จึงไม่ได้ความเป็น Airbnb/Headspace (ภาพประกอบใหญ่ใจกว้าง)
- **แก้:**
  - `Canopy.tsx`: เปลี่ยนเป็น `preserveAspectRatio="xMidYMin slice"` และวาด viewBox กว้างขึ้น (เช่น `0 0 1600 160` โดยทำลอนซ้ำ 4 ชุด) หรือให้ path ซ้ำเป็น `<pattern>` แนวนอน แสงลอดต้องเป็นวงกลมเสมอ
  - `@media (min-width: 1024px) { :root { --canopy: 168px } }` แล้วขยาย `.wordmark` เป็น `--step-2`
  - ให้หัวหน้าเพจที่ ≥1024px เป็น 2 คอลัมน์ ได้แก่ h1+lede ซ้าย และภาพประกอบขวา (`.page-head { display:grid; grid-template-columns: 1fr 280px; align-items:end }`)
  - ให้รายการที่เป็นการ์ด (`.guide-list`, `.feed`) ขยายเป็น `--measure-wide: 64rem` และ `grid-template-columns: repeat(2, 1fr)` ที่ ≥1024px ส่วนหน้าอ่านยาว (Guide, รุ่นพี่) คงคอลัมน์เดียว แต่วาง step rail ใน gutter ซ้าย

### V2 [สูง] หน้าแรก (sheet บนแผนที่) ทั้ง 390 และ 1280: ยังพูดภาษารถไฟฟ้า ขัดกับ ADR 0007
- **ที่เห็น:** `.stop-group ul::before` เป็นเส้นทึบ `width: var(--rail)` (6px) `background: var(--c)` ลากผ่าน station ทุกจุด ซึ่งเป็น "rail" ที่ ADR ประกาศว่าจะเปลี่ยนเป็นทางจุดแล้ว (ใน Guide และสัปดาห์แรกเปลี่ยนแล้ว เหลือแต่ที่นี่) แต่ละที่มี `.price-strip` สี `#ffd100` 14/700 ทำให้บน fold ของมือถือ ของที่ดังที่สุดคือ **เส้นเขียวทึบ + ป้ายเหลือง 2 อัน** ไม่ใช่ชื่อที่ ส่วน `.welcome` ใช้ `border: 2px solid var(--ink)` บนสี `#eef1f6` (ฟ้าเทาที่ไม่อยู่ใน palette) และ `border-radius: 10px` (ไม่อยู่ใน scale) เป็นกรอบดำหนาอันเดียวในหน้า (ดู `z-home-sheet.png`)
- **ทำไมเสีย:** หน้าแรกคือหน้าที่กรรมการเห็นก่อน และเป็นหน้าเดียวที่ยังดูเป็น "ระบบ" ไม่ใช่ "คน" ทั้งที่หน้าอื่นเปลี่ยนแล้ว ความไม่ต่อเนื่องนี้จะสังเกตได้ทันทีเมื่อกดจากแผนที่ไปหน้าวิธี
- **แก้:**
  - `.stop-group ul::before { width:0; background:none; border-left: var(--rail) dotted color-mix(in srgb, var(--c) 40%, var(--paper)); }` ให้ตรงกับ `.steps`
  - `.welcome { border:0; border-radius: var(--radius-m); background: color-mix(in srgb, var(--sun) 55%, var(--paper)); box-shadow: var(--shadow-1); }` ใช้แสงแดดลอดใบไม้แทนกรอบดำ
  - ป้ายราคาคงสีเหลืองตาม ADR 0001 แต่ในรายการให้ลดเป็น `.stop-group .price-strip { padding: 0 var(--space-2); font-size: var(--step--1); font-weight: 600; border-radius: var(--radius-pill); }` ส่วนตัวใหญ่ 18–20px เก็บไว้ใช้ในการ์ดรายละเอียด

### V3 [สูง] หน้ารุ่นพี่ `/seniors` (ทุกจอ): ยังไม่ได้ย้ายมาใช้ look ใหม่ และบล็อกกรมท่าหนักที่สุดในเว็บ
- **ที่เห็น:** เรื่องของพี่ (`.story`) ไม่มีการ์ด มีแค่ `.story-body { border-left: var(--station-ring) solid var(--ink) }` ซึ่งเป็นแถบดำ 4px ยาว 283px ต่อเรื่อง คอมเมนต์ใน CSS บอกว่า "A Senior's words look like a Note: the same bar" แต่ตอนนี้โน้ตเป็นการ์ดแล้วและไม่มีแถบนี้ จึงไม่ตรงกันแล้ว avatar เป็นวงกลม `--ink` ทึบ ส่วน `.help` เป็นแถบเต็มจอ `background: var(--ink)` สูง 511px (26% ของหน้า) ปุ่มเบอร์โทรเป็นกล่องขาว radius 6px ตัวหนา 20px (ดู `m-seniors.png`, `w-seniors.png`)
- **ทำไมเสีย:** หน้านี้คือ "หน้าคน" ตาม ADR แต่กลับเป็นหน้าที่เย็นและแข็งที่สุด สีกรมท่าทึบเต็มจอให้ความรู้สึกเตือนภัยหรือ footer องค์กร ไม่ใช่ "คุยกับคนได้" แบบ Headspace
- **แก้:**
  - `.story { background: var(--paper); border-radius: var(--radius-m); box-shadow: var(--shadow-1); padding: var(--space-5); }` + `.story + .story { margin-top: var(--space-4) }` แล้วลบ `border-left` ของ `.story-body` (หรือใช้มุมใบไม้แบบเดียวกับ `.note`)
  - avatar: `background: var(--tint); color: var(--on-tint)` ตามหมวดของเรื่อง หรือใช้หน้า Open Peeps ทีละคน
  - `.help`: ให้อยู่ใน `.inner` เป็นการ์ด `border-radius: var(--radius-m); background: color-mix(in srgb, var(--leaf) 16%, var(--paper)); color: var(--ink)` ส่วนปุ่มโทร `.help-contact` เป็น pill `--leaf-dark` ตัวขาว หรือถ้าอยากให้ดังต่อ ใช้ `--leaf-dark` ทึบแทน `--ink`

### V4 [สูง] สัปดาห์แรก `/checklist` สถานะ "ทำแล้ว" และ "ครบ 7": ไม่มีเครื่องหมายถูก และฉากฉลองแทบไม่ต่างจากเดิม
- **ที่เห็น:** `.week-stops input:checked { background: var(--c) }` ได้วงกลมทึบเปล่า ไม่มี ✓ (ต่างจาก step-end ของ Guide ที่มีเครื่องหมายถูก) ชื่อข้อเป็น `line-through` หนา 2px สี `--ink-soft` พอติ๊กครบ 7 ข้อ หน้าจอจึงกลายเป็นวงกลมทึบ 7 สีเรียงกับข้อความขีดฆ่าสีเทา 7 บรรทัด (`m-checklist-7.png`) สิ่งเดียวที่ฉลองคือข้อความ "ครบแล้ว ตั้งหลักได้แล้ว" 20px กับภาพ Peeps ชุดเดิม (V7) และ `.week-hint` "กดวงกลมเมื่อทำแล้ว…" ยังแสดงอยู่
- **ทำไมเสีย:** ช่วงนี้เป็นจังหวะอารมณ์ที่ดีที่สุดของเว็บ (Headspace จะให้ช่วงนี้เป็นจุดพีค) แต่ภาพที่ได้เหมือนรายการที่ถูกยกเลิก การขีดฆ่าบนอักษรไทยที่มีสระบนล่างยังทำให้อ่านยากและดูสกปรก
- **แก้:**
  - `.week-stops input:checked { background: var(--c) url("data:image/svg+xml,…check stroke #fff…") center / 60% no-repeat; }`
  - เปลี่ยน `.week-stops .is-done a { text-decoration: none; color: var(--ink-soft); }` (สีที่จางลงพร้อม ✓ ก็พอ)
  - เมื่อครบ 7 ข้อ ให้ `.week-progress` เป็นการ์ด `background: color-mix(in srgb, var(--sun) 60%, var(--paper)); border-radius: var(--radius-m); padding: var(--space-5)` หัวข้อใช้ `--step-2` Mitr และซ่อน `.week-hint` ให้ Peeps อยู่ในการ์ดนี้ (ใช้ท่าอื่นที่ดีใจ เช่นชูมือ) และเปลี่ยนแถบความคืบหน้าเป็น `--leaf`

### V5 [กลาง] ปุ่มหลักและป้ายที่ดังที่สุดทั้งเว็บเป็นสีกรมท่า `--ink` ไม่ใช่สีของร่มไม้
- **ที่เห็น:** ปุ่ม "เขียนโน้ต" (`/notes`, sheet), "ลงโน้ต", "บันทึกราคา/เรื่อง/ยืนยันวิธีนี้", `.next-badge` "ถัดไป", `.help`, avatar รุ่นพี่ และกรอบ `.welcome` ล้วนใช้ `#1d2733` ทึบ ส่วนสีเขียวใบไม้ (`--leaf`, `--leaf-dark`) ปรากฏแค่ใน canopy และแถบความคืบหน้า
- **ทำไมเสีย:** มี palette แล้วแต่ไม่ได้ใช้กับสิ่งที่ผู้ใช้กด เลยดูเป็น admin UI สีดำวางบนพื้นอบอุ่น จุดที่ดังที่สุดของแต่ละจอไม่ได้เป็นตัวแทนของธีม
- **แก้:** เพิ่ม token `--action: var(--leaf-dark)` (ตัวขาวบนพื้นนี้วัดได้ประมาณ 5.3:1) และ `--action-press: color-mix(in srgb, var(--leaf-dark) 85%, #000)` ใช้กับ `.head-action`, ปุ่ม submit ของฟอร์ม และ `.next-badge` ส่วน `--ink` เก็บไว้สำหรับตัวอักษรอย่างเดียว

### V6 [กลาง] สัปดาห์แรก 390: station อัดกันจนทางจุดหายไป และวงแหวนสีหนา 7 วงดังกว่าชื่อข้อ
- **ที่เห็น:** `.week-stops li { min-height: 48px }` ทำให้วงกลม 40px ห่างกันแค่ 8px ทางจุด (`::after` dotted) จึงเห็นเฉพาะข้างการ์ด "ถัดไป" ส่วนข้ออื่นวงแหวนแทบชนกัน วงแหวนหนา 4px ในสีหมวดเต็ม 6 วงติดกัน (เขียว ส้ม น้ำเงิน ×3 ดำ) เป็นกลุ่มสีที่หนักที่สุดของหน้า (`m-checklist.png` y=510–790)
- **ทำไมเสีย:** ความรู้สึก "แออัด" ยังเหลืออยู่ในหน้านี้ และภาษา "เดินทางทีละสถานี" ที่ตั้งใจไว้หายไปเพราะมองไม่เห็นทาง
- **แก้:** `.week-stops li { min-height: 64px; }` + `.week-stops li + li { margin-top: var(--space-2) }` ข้อที่ยังไม่ทำให้ใช้ `border-width: 3px; border-color: color-mix(in srgb, var(--c) 55%, var(--paper)); background: var(--tint)` (สีเต็มเก็บไว้ให้ข้อที่ทำแล้วและข้อ "ถัดไป") และสีทางจุดเป็น `color-mix(in srgb, var(--leaf) 50%, var(--rule))` เพื่อให้มองเห็นตลอดทาง

### V7 [กลาง] ภาพ Open Peeps ชุดเดียว (3 คนเดิม) ซ้ำ 3 หน้า ขนาดและตำแหน่งเดียวกัน
- **ที่เห็น:** `<Peeps>` ใน `/notes` (`.feed-peeps` สูง 124px คั่นระหว่าง lede กับ chip ดันโน้ตแรกลงไปที่ y=403), `/seniors` (124px) และ `/checklist` ตอนครบ (`.week-cheer`) ทั้งสามที่ใช้ภาพเดียวกันและจัดกลางเหมือนกัน
- **ทำไมเสีย:** ภาพประกอบควรเป็นรางวัลของแต่ละหน้า เมื่อเห็นซ้ำตั้งแต่ครั้งที่สอง มันกลายเป็นสติกเกอร์ที่ "แปะ" ไว้ ซึ่งก็คือคำบ่นเดิมนั่นเอง และบน /notes ยังกินพื้นที่จอแรกไป 124px
- **แก้:** ทำภาพ 3 ชุดจาก Open Peeps ที่ต่างกัน ได้แก่ โน้ต (คนเขียนหรือถือโทรศัพท์ 1–2 คน), รุ่นพี่ (พี่คุยกับน้อง 2 คน), ครบสัปดาห์ (ชูมือ) บน /notes ให้ย้ายภาพไปอยู่ขวาของ h1 (`.page-head { display:grid; grid-template-columns: 1fr auto }`, ภาพสูง 96px) แทนการใช้แถวเต็ม

### V8 [กลาง] ฟอร์ม `/notes/new` และ `/contribute`: ยังเป็นฟอร์มเปลือยบนพื้น ไม่อยู่ในภาษาการ์ด
- **ที่เห็น:** input/select มี radius 6px (`measure.json`: 13 ชิ้นที่ 6px บน /contribute) ขณะที่การ์ดทั้งเว็บใช้ 18px ฟอร์มสามชุดของ /contribute ต่อกันเป็นคอลัมน์ยาว 2601px คั่นด้วยเส้นบาง ส่วนเมนูภายในหน้าเป็นลิงก์ขีดเส้นใต้ 3 อันที่ตกเป็น 2 บรรทัด (`m-contribute.png`)
- **ทำไมเสีย:** หน้าที่ขอให้คนช่วยเขียนดูเหมือนฟอร์มราชการ ซึ่งขัดกับ "Senior ดูแล Newcomer" และไม่เข้ากับหน้าอื่นที่เพิ่งเปลี่ยน
- **แก้:** `.contribute-form, .note-form { background: var(--paper); border-radius: var(--radius-m); box-shadow: var(--shadow-1); padding: var(--space-5); }` + `margin-top: var(--space-5)` ระหว่างฟอร์ม เพิ่ม token `--radius-field: 12px` ใช้กับ `input, select, textarea` และเปลี่ยนเมนูในหน้าเป็น `.line-chip` แถวเดียวแบบเลื่อนได้ เหมือนบน /guides

### V9 [กลาง] Feed `/notes`: การ์ด 11 ใบหน้าตาเหมือนกันหมด และ "มุมใบไม้" มองไม่ออก
- **ที่เห็น:** `.feed .note` ใช้ `border-radius: 6px 18px 18px` (ต่างกันแค่ 12px ที่มุมเดียว ซึ่งดูไม่ออกที่ 1x ตาม `z-note.png`) สีหมวดเหลือแค่ใบไม้ 8px หน้าคำว่าหมวด ทุกใบเป็นสีขาว เงาเท่ากัน และห่างกัน 24px

## สิ่งที่ทำได้ดีแล้ว (อย่าย้อนกลับ)

- **หน้า Guide (`/guides/rabbit`, `/guides/sick`)** คือหน้าที่ดีที่สุดในเว็บ: การ์ดขั้นตอนสีขาวมีเงานุ่ม ทางจุดเชื่อม station ส่วน "พูดว่า" ใช้ tint สีหมวด "เตรียมให้พร้อม" เป็นการ์ด tint ปิดท้ายด้วย ✓ "เท่านี้เอง" และการ์ด "ต่อจากนี้" ควรใช้เป็นมาตรฐานให้หน้าอื่นเทียบ
- **Typography:** Mitr 500 สำหรับ h1/h2 และ IBM Plex Sans Thai Looped สำหรับเนื้อหา ใช้สม่ำเสมอ ทุกหน้ามี h1 32px/500 เท่ากัน (วัดแล้ว) และตัวเลขยังอยู่ในฟอนต์เนื้อหาตามที่ตั้งใจ
- **พื้นครีม `--ground` + การ์ด `--paper` + `--shadow-1`** ให้ความลึกที่นุ่ม ไม่แข็ง ส่วนรายการวิธี (`.guide-list`) อ่านง่ายและห่างกันกำลังดีบนมือถือ
- **การ์ด "ถัดไป" ในสัปดาห์แรก** (tint, ป้าย, ชื่อ 18px, "อ่านวิธี →") เป็นจุดเด่นเดียวของหน้าตามหลัก "หนึ่งจอหนึ่งจุดเด่น" แถบความคืบหน้าสีเขียวใบไม้ก็ใช้ได้
- **Motion** มี rise-up พร้อม stagger 50ms, ปุ่มยุบ 0.97, วงกลม pop 1.18 และ canopy sway 9s ทั้งหมดอยู่ใน `prefers-reduced-motion: no-preference` นุ่มและเล็กตามที่ ADR กำหนด
- **ป้ายราคาสีเหลือง** มีความหมายเดียวทั้งเว็บ (ราคา) ควรเก็บไว้ แค่ลดน้ำหนักในรายการตาม V2
- **Chip กรองบน /guides และ /notes** มีไอคอนสีหมวด ขอบบาง และสถานะเลือกเป็น tint + ✓ ถูกต้องแล้ว
- ไม่มี horizontal scroll ในทุกหน้าที่ 360/390/1280
